Modern Responsive Navigation Bar

This navigation bar is fully responsive with a hamburger menu on mobile devices. It features:

  • Clean, modern design with smooth transitions
  • Logo on the left, navigation links in the center/right
  • Call-to-action button with hover effects
  • CSS variables for easy customization
  • Minimal JavaScript only for mobile toggle
  • Accessible with ARIA attributes
Customization Tip: Change colors by editing the CSS variables in the :root selector. For example, to change the primary color, modify --primary-color.

Resize your browser window to see the responsive behavior. On mobile screens (≤768px), the navigation collapses into a hamburger menu.

How It Works

Desktop: Navigation links are displayed horizontally with the CTA button on the right.

Mobile: Navigation links are hidden by default. Clicking the hamburger icon toggles a vertical menu with smooth transitions.

/* Mobile menu toggle with minimal JavaScript */
const hamburger = document.getElementById('hamburger');
const navMenu = document.getElementById('nav-menu');

hamburger.addEventListener('click', () => {
  hamburger.classList.toggle('active');
  navMenu.classList.toggle('active');
});

Customization Guide

Easily customize the navigation bar by modifying these CSS variables:

  • --primary-color: Main theme color (links, button)
  • --primary-dark: Darker shade for hover states
  • --text-color: Text color for links
  • --nav-height: Height of navigation bar
  • --transition-speed: Speed of animations
  • --border-radius: Roundness of corners
